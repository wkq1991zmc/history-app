## 四、主理人偏好（来自前会话明确反馈）

这些是主理人在前一个会话验证序章+洛阳两章时反复明确的偏好，**你必须吸收**：

### 4.1 阿萤的"冷"是防御不是攻击

主理人对早期一版台词的反应（已修正）：

> ❌ "够了。别盯着我看，走远点。" / "你睡你的，别管我。" / "死了。别问这种废话。"

主理人原话："**她吃了我的东西，没必要这么冷淡。**"

正确方向：
> ✅ "嗯。" / "……睡不着。" / "死了。" / "……以前的事，不说了。"

**禁用任何 push-back 攻击性句式**（"走远点"/"别管我"/"别问废话"/"管你什么事"）。她是评估对方，不是赶走对方。`AYINGHUO_PERSONA` in `sanguo_ai.py` 已写硬约束，但你写剧本对白时也必须遵守。

### 4.2 阿萤不能说粗口（女性化）

主理人反馈过原版 "**你他娘的乱世里背笔？**" 太男性化，改成 "**……乱世里背笔？**"。后续涉及阿萤台词遵循同原则。

### 4.3 剧本要把"为什么"讲清楚，不要文学含蓄到玩家一头雾水

主理人原话（指荀彧来访那段早期含糊版）：

> **"你写的'在下来，只为见阁下一面，说两句。再问几句，便要走了'——为啥见我？说两句是说了什么？看完还是一头雾水。"**

正确做法：让 NPC 把自己的来意 / 动机 / 玩家的处境 / 接下来该怎么办**都说清楚**，再交给玩家自由问。

"命运钩子不是侦探钩子" 的原则**不等于**让玩家猜不到当下在发生什么。**该说清楚的事必须清楚说**。

参考已修正的 `chapters/02_luoyang.md` 中 9.3.5 段（"在下颍川荀彧。" 之后的 16 行新对话），那是符合主理人标准的样本。

### 4.4 标点：句中破折号 `——` 不要用太多

主理人在荀彧段反馈过原版 7 处 `——` 太密。最终版稀释到 1-2 处。

你写时**句中 `——` 每节点最多 2 处，且只用在最重的判断**。其他停顿用句号 / 逗号 / 冒号。

### 4.5 行首的 `—— 角色名：` 是 UI 约定，不能换

参考 `04_UI_SPEC.md` §7.2。所有对白前置 `—— X：` 是项目格式，前端按此渲染（破折号代替名字框）。你写剧本必须保持。

### 4.6 节奏：2-3 句一屏

`05_WRITING_STYLE.md` §8.1 第 2 条。长描写必须拆分。每行对白短到一屏能舒服看完。

### 4.7 "无功用"留白时刻

每章至少 2-3 段"什么都没在推进剧情"的场景（阿萤吃饼、火光里看主角写字、夜里听马蹄过桥等）。这些是情感栖息地。

### 4.8 给方案而不是给问题

主理人重要决策喜欢"3-4 个选项 + 利弊"，不喜欢"我该怎么办？"式开放问句。你设计剧情分支或文风时也按此模式给主理人选。

### 4.9 主理人对历史人物视角的偏好

参考 `01_STORY_BIBLE.md` 三款游戏 + §8.1 第 6 条：**远观历史，不参与历史**。重大历史事件以"路过 / 瞥见 / 听人说"呈现，主角不是英雄。

## 五、你不能做的事

1. **不能用《三国演义》虚构情节作为正史背景**（详见 `07_HISTORICAL_SOURCES.md` C 级清单）
2. **不能让历史人物预言未来**（189 年的荀彧不知道 207 年的事；任何时点人物只能说当下该知道的）
3. **不能改动公开课"礼法断案"内容**（那是另一个独立模块，技术上完全隔离，但你不要在剧本里引用或干扰）
4. **不能写超过 30 字一句的连续旁白**（节奏破坏）
5. **不能在 AI 节点（companion_free_talk / historical_limited_talk）里写死对白**——那些节点是 AI 实时生成，你只能写状态卡 / 知识边界卡，不能写具体对白
6. **不能给历史人物超过 5 轮的对话**（hard limit）
7. **不能让选择"看起来不同但结果相同"**——每个关键选择必须有真正不同的后果（永久影响后续）

## 八、常见操作模板

### 8.1 你接到"写第 X 站"任务时

```
1. 重读 PROJECT_BIBLE §4 章节结构表，确认这一站的历史时间、地点、基调、字数
2. 重读 02_CHARACTERS 中本站涉及的历史人物条目
3. 查 07_HISTORICAL_SOURCES，列出本站涉及的 A 级史料（如《三国志·王允传》《后汉书·董卓传》等）
4. 起草本章结构：N 个 scene + 哪些是 AI 节点 + 关键抉择在哪 + relationship_stage 变化点
5. 把结构给主理人审，确认后再写细节对白
```

### 8.2 涉及历史人物对白时

```
1. 写"知识边界卡"（按 06_PROMPT_TEMPLATES §6.3 模板）：
   - identity / place / time
   - knows（当前时点 + 此前发生的事，按 A 级史料列）
   - doesnt_know（未来事 / 其他诸侯未来命运）
   - core_stance（按 A 级史料定调）
   - will_never_do
   - rounds_limit（3-5）
   - fallback_lines（3-5 句通用回避，符合人物口吻）
2. **不写历史人物的具体对白**——AI 会按知识边界卡生成
3. 只写人物出场前后的剧情骨架（旁白 + 主角的反应 + 场景描写）
```

### 8.3 涉及 AI 自由对话节点（阿萤）时

```
1. 写"状态卡"（按 06_PROMPT_TEMPLATES §6.2 模板）：
   - time / place
   - recent_event（她刚经历什么）
   - current_emotion
   - knows / wont_say
   - current_hints_allowed（本节点可漏的具体暗示句）
   - rounds_limit（通常 null）
   - secrets_hint_allowed（按 02_CHARACTERS §5.2.1 权威清单）
   - secrets_reveal_allowed（仅锁定章节内特定节点开放）
   - relationship_stage（按 02_CHARACTERS §5.2.2 阶段表）
2. **不写阿萤具体对白**——AI 实时生成
3. 只写节点前的剧情骨架引子（如"半夜阿萤忽然坐起来。…… 睡不着。"）+ 节点退出条件
```

### 8.4 涉及关键抉择时

```
1. 给主理人 3-4 个选项 + 每个选项的后果 + 哪个是默认推荐
2. 每个选项必须有真正不同的命运后果（不是 A 礼貌 B 不礼貌）
3. 每个选项 10-15 字
4. 选项之间引向真正不同的剧情分支或情感色彩
```
