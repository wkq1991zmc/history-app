# 终章 · 荆州 / 赤壁

时间：建安十二年至建安十三年（公元 207—208）
地点：荆州 → 长坂 → 赤壁
历史背景：三顾茅庐、刘表死、长坂坡、赤壁
基调：史诗悲壮（三者融合的高峰）
字数估算：5 万

## 情感弧定位

参考 [`../01_STORY_BIBLE.md`](../01_STORY_BIBLE.md) §4.2：

> **终章**：赤壁。两人的故事在这里得到结局。**阿萤是否活到最后是玩家选择决定的，但任何一条线最终都指向"小人物在大时代里的位置"这个命题**。

## 多结局分支

参考 [`../01_STORY_BIBLE.md`](../01_STORY_BIBLE.md) §4.4：

| 结局 | 条件 | 收尾 |
|---|---|---|
| **"长河"**（默认好结局） | 阿萤未死于第五站 + 多数选择倾向同行 | 赤壁后两人隐居荆南，阿萤活着 |
| **"独行"** | 阿萤死于第五站 | 主角独自走完赤壁 |
| **"同尘"** | 两人都死在徐州（第三站某分支） | 以阿萤未说出口的话作结 |
| **"洛阳路"**（隐藏） | 第一站选择留下洛阳，被卷入十常侍之乱 | 主角死于洛阳，**不进入终章** |
| **"无名"**（真结局） | 完成全部支线+所有"留下记录"选择 | 主角的笔记在战乱中被埋藏；多年后被挖出；开篇画面再次出现——但**主角名字的位置永远空白** |

## 核心历史人物

- **诸葛亮**（远观/三顾）：隆中
- **周瑜**（短暂对话）：赤壁前

> **正史边界提醒**：诸葛亮"三顾茅庐"史实仅记载有此事，无具体对话场景，可虚构氛围但不能虚构对话；赤壁火攻是周瑜与黄盖之策，无诸葛亮"借东风"。
