# 第二站 · 长安

时间：初平三年（公元 192）至兴平年间（193-194）
地点：长安
历史背景：王允密谋诛董、董卓被杀、李傕郭汜之乱、长安饥荒
基调：饿殍式沉重（与第三站徐州屠城形成连续主题）
字数估算：4 万

## 情感弧定位（修正版）

参考 [`../01_STORY_BIBLE.md`](../01_STORY_BIBLE.md) §4.2：

> **第二站**：第一次看见"权力之内的人"也是凡人。阿萤的过去开始浮现。

**重心由原方案"貂蝉悲剧"改为"李傕郭汜之乱后的长安饥荒"**：
- 长安饥荒是 A 级《后汉书·董卓传》《资治通鉴》记载的真实历史：兴平元年 (194) 三辅大旱、谷价腾贵；李傕郭汜的部下大肆掳掠；"人相食啖，白骨委积"
- 惨烈程度堪比明末，正好与第三站徐州（曹操屠城）形成连续的"饥荒 / 屠杀"主题
- 阿萤目睹长安饥荒会引出她的村子被烧记忆，为第三站徐州揭开秘密一"捂死弟弟"做铺垫
