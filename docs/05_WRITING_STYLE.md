# 写作风格规范

---

## 8.1 必须遵守的写作原则

1. **情感先于名词**——读者还没建立情感连接时，不要堆专有名词。先写人，再写身份。
2. **2—3 句一屏**——剧本格式假设每屏只能容纳 2—3 句话。长描写必须拆分。
3. **"无功用"的留白时刻**——每章必须有至少 2—3 段"什么都没在推进剧情"的场景。这些是情感栖息地。
4. **命运钩子，不是侦探钩子**——读者读下去的动力应该是"这些人会怎样、这个世界会怎样、我会怎样"，而不是"谜底是什么"。
5. **角色描写融入环境/动作**——没有立绘，所以"她紧抿嘴唇"要写成"火光照亮她半张脸，嘴唇抿得发白"。
6. **远观历史，不参与历史**——重大历史事件必须以"路过"、"瞥见"、"听人说"的方式呈现。
7. **每屏文字越短越好**——能用 30 字说清楚的，绝不用 60 字。
8. **避免现代化语言**——不用"OK"、"系统"、"机制"等现代词。但也不必强行半文半白，自然现代汉语即可。

---

## 8.2 必须避免的反面教材

参考主理人之前生成的"唐天宝末年驿卒失踪"故事（即"驿路无名"，已被否决）。它的问题：

1. **侦探化叙事**——主角是"采访使幕府随行书吏"，带着差牒去查案。这是悬疑小说视角，不是史诗小说视角。
2. **信息密度爆炸**——开场连续砸下"采访使、幕府、随行书吏、临皋、怀远驿、差牒、驿卒"等一堆专有名词。
3. **角色工具化**——所有同伴都是"案件需要"的角色，没有独立的人生。
4. **历史只是背景板**——安史之乱在最后一行才出现一句"范阳兵反"，整个故事跟历史没有真正的互动。
5. **每秒都在推进**——没有让读者喘气的地方，所有对话都在累积线索。

**接手 Claude 必须避免这些倾向。当你的剧本开始变成"高密度悬疑"时，立刻停下，问自己："这个故事是在'走完一段路'，还是在'解开一个谜'？"**

## 8.3 文笔示例（已通过审美的开场）

```
*中平元年，三月。*
*涿郡的春天来得迟，桃花刚开。*

*画面：一条被踩烂的乡道。远处有烟柱，三四根，弯弯地立在田野尽头。
一个少年背着行囊独自走着，鞋底裂了一道口子，脚趾露在外面。*

*路旁一棵歪脖子槐树下，蜷着一个老妇人，怀里抱着一个孩子。*

**老妇人**（声音几乎听不见）：……水……

*少年停下脚步。*
```

注意：
- 没有专有名词
- 视觉清晰（"鞋底裂了一道口子"）
- 没有解释"主角是谁"
- 用"水"一个字建立第一个情感联系
- 留白：少年停下脚步——还没说做什么

---

## 8.4 选择写作的规则

- 选项数量：通常 3 个，最多 4 个
- 每个选项**字数控制在 10—15 字**
- 选项之间应该有**真正的不同**（不是 A 礼貌、B 不礼貌的换皮），而是引向真正不同的命运
- 关键选择（一章结尾级别的）会**永久影响后续**，不可回头

---

## 8.5 自检清单（每章完成时使用）

写完一章后，逐条对照：

- [ ] 是否在前 3 屏内堆了专有名词？
- [ ] 每屏是否在 3 句之内？
- [ ] 是否有 2-3 段"无功用"留白时刻？
- [ ] 推动读者读下去的是"命运钩子"还是"侦探钩子"？
- [ ] 重大历史事件是不是"路过/瞥见/听人说"，而不是主角直接参与？
- [ ] 选项之间是否引向真正不同的命运？
- [ ] 阿萤的语气是否冷而短，没有撒娇？
- [ ] 历史人物是否说了他/她当时不可能说的话？
- [ ] 是否出现了《三国演义》的虚构情节作为正史？

任何一条没过，回去改。
