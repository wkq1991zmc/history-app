# UI / UX 设计想象（从零设计）

---

## 7.1 整体哲学

**"电影 × 古籍"的混合体**。

- 不要游戏感，要文学感
- 黑色（`#0a0907`）背景 + 暖灯色（`#d4a557` / `#e8b865`）文字 —— 不是金色，是煤油灯橙黄色
- 字体：
  - 标题用书法（楷书或行楷）
  - 正文用宋体或仿宋
  - 主角心声用更纤细的楷书体
- 整体留白多，呼吸感强
- 节奏感参考是枝裕和电影或《对马岛之魂》而非传统 Galgame

---

## 7.2 主屏布局（剧情进行时）

```
┌─────────────────────────────────────────────────┐
│  序章 · 涿郡 / 中平元年三月        卷 言 乐 声  │  ← 顶栏（半透明）
│                                                  │
│                                                  │
│           [全屏背景画面 - 数字水墨风]            │
│                                                  │
│                                                  │
│                                                  │
│                                                  │
│        ┌──────────────────────────────┐         │
│        │                               │         │
│        │   少年停下脚步。              │         │
│        │   路旁一棵歪脖子槐树下，      │         │
│        │   蜷着一个老妇人……            │         │
│        │                               │         │
│        │                          继续 ⌐│         │
│        └──────────────────────────────┘         │
│                                                  │
└─────────────────────────────────────────────────┘
```

- **背景画面**：全屏铺满，不窗口化。风格类似《燕云十六声》宣传画的数字水墨/写实数字绘画，**非动漫风格，非真人**。
- **文字区域**：位于屏幕下方约 1/3 处，居中，宽度约 60%。**没有对话框边框**，文字直接浮在画面上（背景画面在文字下方有一层极淡的暗化叠层，保证可读性）。
- **文字层级**：
  - 旁白：浅暖白（`#f0e8d8`），字号略小
  - 角色对白：前置一个"—— "破折号代替名字框，颜色与旁白同
  - 主角心声：浅灰（`#9a9a8a`），斜体
  - 阿萤的话：略带暖色（`#e8d5b0`）——细微差别，玩家会潜意识感知到
- **顶栏图标**：
  - 卷：笔记本（已记录的事件、印章）
  - 言：自由对话（在 AI 对话节点可点亮）
  - 乐：背景音乐开关
  - 声：朗读开关（如果做配音）

---

## 7.3 选择呈现

不是按钮列表，而是**浮现在画面下方的竖排印章式选项**：

```
        〇  把剩下半囊水递给她
        〇  假装没听见，继续走
        〇  蹲下，问她从哪里来
```

- 每个选项前的 "〇" 是一个"印章"图标，hover 时印章泛红光
- 点击后有"印章落下"的音效（"啪"一声）
- 选定后选项变为单行红章："已落子 — 蹲下，问她从哪里来"
- 然后剧情继续

---

## 7.4 AI 自由对话界面

当玩家可以自由输入时（阿萤的对话节点）：

1. 屏幕下方原本的"继续"按钮位置出现一个**"言"字毛笔印章**
2. 点击后，画面变暗（70% 黑色叠层），中间浮现一个**仿古纸的输入框**
3. 输入框内字体是**毛笔字效果**（前端实现：自定义字体或 SVG 笔画动画）
4. 玩家提交后纸消失，回到剧情画面
5. 对方的回复以正常的"角色对白"格式呈现
6. **每次自由对话结束后，"言"按钮持续显示，玩家可继续呼出对话**——直到玩家点击"继续"推进剧情

---

## 7.5 历史人物对话特殊标记

历史人物出现时：
- 画面右上角浮现一个**朱红色"史"字印章**
- 印章下方有一个小字提示："剩余可问：3 / 5"
- 印章在对话期间常驻
- 历史人物对话用稍微不同的颜色（深红 `#c87878`）以与日常 NPC 区分

---

## 7.6 笔记本系统

主角的笔记本是一个核心系统，对应剧情里"主角在记录历史"的设定。

- 顶栏点击"卷"图标 → 进入笔记本界面
- 笔记本是一本可以翻页的古籍样式
- 内容：
  - **"日录"**：自动记录玩家走过的关键事件（"中平六年八月初九，董卓入洛。百姓跪满铜驼街。"）
  - **"人印"**：遇见过的历史人物，每人一枚印章，附简短笔记
  - **"地图"**：行旅图，红线标注走过的路
  - **"心事"**：主角对阿萤等伙伴的内心独白（隐藏，进度推进解锁）
- **笔记本是存档点**——主角"在笔记本上写下今日"的过场动画就是自动存档点（不打断剧情）

---

## 7.7 章节切换

每站之间用**地图过场动画**：

- 一张水墨地图缓缓铺开
- 红色"主角行迹"线从上一站延伸到下一站
- 顶部出现新站标题（书法字）："第二站 · 长安 / 初平三年"
- 副标题：一句概括（"董卓死于义女门前"）
- 按任意键进入

---

## 7.8 时间与状态指示

- **不显示**：HP / MP / 金币 / 经验值 / 等级（这是视觉小说，不是 RPG）
- **显示**：
  - 顶栏左侧：站名 + 时辰（用古风：丑时三刻、卯时初、酉时末）
  - 卷（笔记本）里查看：与主要 NPC 的关系状态（用文字描述："阿萤·愿意为你流泪"而非"阿萤·好感度 78"）

---

## 7.9 音效与音乐

- **背景音乐**：中式古乐（古琴、箫、笛），但避免过度民俗化。参考《天地劫》《古剑奇谭三》《对马岛之魂》的配乐。
- **环境音**：风、雨、火、马蹄、远处的喧闹——非常重要的氛围工具。
- **UI 音效**：印章落下、毛笔书写、翻页、火苗噼啪。
- **角色配音**（如做）：阿萤建议是温度低、不刻意可爱的少女声。

> **注**：codex_handoff 已确认配音不是核心。三国篇第一版**不做配音**，优先 BGM、环境音、关键音效。

---

## 7.10 视觉风格参考

- **整体调性**：《天地劫·幽城再临》 + 《剑网三》宣传画 + 《燕云十六声》原画
- **避免**：anime 风格、Q 版、过度卡通化、过度真实化、好莱坞电影感
- **关键词**："墨"、"灯"、"夜"、"雪"、"血"、"纸"

---

## 7.11 技术实现路径（SETUP_GUIDE 附录 D 建议）

按上述哲学实现时，建议技术路径：

1. **全屏画面 + 字幕式文字**：纯 CSS 即可，不需要 Canvas
2. **"印章式"选择按钮**：CSS `border-radius: 50%` + 自定义 hover 动画
3. **"言"按钮的仿古纸输入框**：CSS overlay + 自定义字体（毛笔字效果可用 `font-family: '楷体', 'KaiTi'` 或导入 web 字体）
4. **章节切换的地图过场**：SVG + CSS 动画（路径动画）
5. **笔记本翻页**：CSS 3D transform 或者用 `turn.js` 等库

不需要引入大框架（React/Vue），保持现有 vanilla JS 风格即可（与 history-app 现有惯例一致）。
