# 史料权威等级与查证工作流

任何涉及历史人物的言行、时间、地点、官职、礼制、地名、风物、政治军事决策等内容，**必须在写之前**按本文档查证。绝不能凭印象、百度百科或模糊"历史常识"下笔。

---

## A 级 — 绝对权威（必须以这些为准）

凡涉及东汉末至三国时期史实：

| 来源 | 作者 | 时代 |
|---|---|---|
| 《三国志》 | 陈寿 | 西晋初 |
| 《三国志》裴松之注 | 裴松之 | 南朝宋 |
| 《后汉书》 | 范晔 | 南朝宋 |
| 《资治通鉴》东汉末三国部分 | 司马光 | 北宋 |
| 《华阳国志》 | 常璩 | 东晋 |
| 当时人物本人著作 | 诸葛亮《出师表》、曹操诗文、孔融书信、王粲诗赋、陈琳檄文等 | 同时代一手 |

**A 级是默认基准**。所有历史事件的时间、地点、参与者、结果、人物核心立场都必须以 A 级为准。

---

## B 级 — 参考但需鉴别（不能作为唯一依据）

可参考，但单独使用 B 级时**必须在文档/剧本里明确标注"此处依据 B 级来源，非一手史料"**：

- 《世说新语》（南朝宋·刘义庆）—— 多为轶事记录，需对照 A 级
- 现代严肃学术专著：
  - 吕思勉《三国史话》
  - 田余庆《秦汉魏晋史探微》
  - 田余庆《东晋门阀政治》
  - 万绳楠整理《陈寅恪魏晋南北朝史讲演录》
- 各类典章制度志：
  - 《通典》（杜佑·唐）
  - 《文献通考》（马端临·元）

---

## C 级 — 禁用（绝不能作为史实依据）

任何剧本、文档、对白若发现使用 C 级来源，**立刻停下，重新查 A 级**：

- 《三国演义》《三国志平话》——后世小说
- 后世戏曲、杂剧、评书——艺术加工
- 百度百科、知乎、各类网络"历史科普"——错误率极高，部分内容直接来自演义
- 标注"野史"的来源——定义本身就排除了史料可靠性
- 影视剧、游戏——艺术二次创作

---

## 冲突仲裁规则

当 A 级或 B 级史料之间有冲突时，按以下优先级判断：

1. **一手优先**：当事人本人著作 > 第三方记载
2. **时间近优先**：《三国志》（西晋）> 《资治通鉴》（北宋）；《后汉书》（南朝宋）> 后世
3. **史学家明确背书优先**：裴松之注里被裴注采用的说法权重高于裴注质疑的说法
4. **如果史料明确冲突且权威各异**——**停下来汇报给用户和策划 Claude，不要自己拍板**

## 实际工作流

### 标准流程

```
要写一处涉及史实的内容
        ↓
查 A 级
        ↓
查到 ──→ 按 A 级写
        ↓
查不到 → 查 B 级
        ↓
查到 ──→ 按 B 级写，并明确标注"此处依据 B 级来源，非一手史料"
        ↓
查不到 → 这说明史实空白
        ↓
属于虚构空间（人物日常、空白场景）─→ 可虚构
                              └→ 涉及具体历史事件细节 → 不能虚构，调整剧情绕开
```

### 失败兜底

- 任何时候发现自己在用 C 级来源（甚至只是"听过""印象里"" 好像是这样"）→ **立刻停下，重新查**
- 不确定来源等级 → 当作 C 级，必须查到 A 或 B 级佐证才能用

---

## 触发查证的具体场景

下列场景**必须在动笔前查 A 级**，不能写完再查：

1. 任何历史人物的具体台词（哪怕短到一句）
2. 任何提到历史事件的细节：时间（年份/月份/具体日期）、参与者、地点、结果
3. 任何涉及：
   - **官职**：什么时候担任什么官（董卓什么时候是司空、什么时候是太尉，差几天就错）
   - **礼制**：祭祀、婚丧、朝议规矩
   - **地名**：洛阳铜驼街、长安未央宫等具体方位
   - **风物**：当时的衣食住行、货币、度量衡
4. 任何涉及阴谋诡计、战场决策、政治决策
5. 任何引用历史人物的诗文、上书、檄文

简言之：**不是写完一个剧情后才查，而是在每写一句"史实层面的内容"前就查**。

## 常见易踩坑（持续更新）

| 易错点 | 演义/民间说法 | 正史 |
|---|---|---|
| 张飞职业 | 杀猪卖肉 | 《三国志·张飞传》无记载；《三国志平话》才说杀猪——C 级 |

| 桃园三结义 | 演义"桃园结义" | 史无此事；《三国志·关羽传》"先主与二人寝则同床，恩若兄弟" |

| 借东风 | 诸葛亮 | 无；冬季东南风是当时气候常识，黄盖纵火靠风 |

| 貂蝉 | 王允义女、连环计 | "貂蝉"是演义虚构名字；《三国志·吕布传》仅记"布与卓侍婢私通" |

| 凤仪亭 | 演义虚构场景 | A 级无 |

## 跨朝代扩展（未来朝代用）

本文档当前重点在东汉末三国。未来"入局"扩展到其他朝代（汉/秦/唐等）时，应在此文档同位置增补对应朝代的 A 级史料清单：

- **秦朝**：《史记》（司马迁）、出土秦简（睡虎地、里耶、岳麓等）
- **西汉**：《史记》、《汉书》（班固）
- **东汉**：《后汉书》
- **唐朝**：《旧唐书》、《新唐书》、《资治通鉴》唐部分、《唐六典》、《唐律疏议》
